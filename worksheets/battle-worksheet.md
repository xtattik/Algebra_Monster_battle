## Worked example

Sorcerer + Sprite, magic attack, in Arcane Nexus, vs a Barbarian (Average Strength).
Sprite "Fairy Lights" magic attack `3x + 1` · Sorcerer High Magic `+x` · Arcane
Nexus boosts Magic `+x` · enemy Average Strength `0`. Opponent pet starts on 50 HP.
The die roll is 4.

```
Attack #1   Attack name & type: Fairy Lights — magic

Base attack expression:            3x + 1
my Magic / Agility modifier (+x, −x, or 0):    + x        (High Magic)
environment modifier (+x, −x, or 0):           + x        (Arcane Nexus boosts Magic)
enemy Strength modifier (−x if High, +x if Low, 0 if Average):   0        (enemy Average Strength)

Collect like terms  →              5x + 1

My dice roll (x) =  4

Substitute  →                      5(4) + 1  =  21  damage
(if negative, damage = 0)

Opponent HP:  50  −  21  =  29
```
