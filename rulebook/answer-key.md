# Algebra Monster Battle — Fast-Marking Answer Key

A lookup sheet for marking battle sheets. Once a student has collected like
terms to a single `nx + c`, you do not need to re-derive anything: find the row,
read the value under their die roll, and that is the damage — already floored at
0.

This sheet prints best in **landscape** (the lookup table is wide).

## 1. How to use  *(v2)*

For each attack block on a student's battle sheet:

1. Check the **expression assembled** — the pet's chosen attack `ax + b` plus:
   - their **matching stat** modifier — Magic on a magic attack, Strength on a
     strength attack, Agility on an agility attack (`+x` High / `0` Average / `−x` Low),
   - the **environment** term on that attack type — `+2x` / `+x` (Boost) or
     `−2x` / `−x` (Weaken). If the card **Cancels** that type, the attack is
     unusable — there should be no block for it.
2. Check the **like terms collected** — a single `nx + c`, normally `1 ≤ n ≤ 8`,
   `−3 ≤ c ≤ 3`.
3. Find that `nx + c` in the table below; read the value under the student's die roll.
4. That value **is the final damage** — already floored at 0.

**If `n = 0`** (all the `x` terms cancelled), the expression is just the constant
`c` — damage `c` every roll, floored at 0. Not in the table.

### 2a. Challenge deck — negative and mixed-sign rows  *(v2)*

The Challenge pet deck (`cards/pets-challenge.md`) adds two attack forms:

- **Bracket** (`a(x ± b)`) expands to the *same* `ax + b` family as Core — once
  a student expands it, mark against the §2 (or §2b) table exactly as normal.
- **Negative coefficient** (`−ax + b`) — damage that *shrinks* as the roll
  grows. Once collected into `nx + c`, `n` is usually negative, but a big
  enough favourable stack (High stat **and** a Boost, both on the same type)
  can push a *weak* negative attack (`−x` or `−2x`) into a small **positive**
  `n` — the modifiers overpower the base coefficient rather than just
  softening it. That case is in this table too, not just the negative ones.

## 3. Sample-scenario answers  *(v2)*

Four worked attacks under the v2 model — build the pet attack `ax + b`, add the
matching stat modifier, add the environment term, collect like terms, substitute.

### A. Boost — Sorcerer, magic attack, in Arcane Nexus

- Base: pet magic attack `3x + 2`
- Sorcerer **High Magic** → `+x`
- **Arcane Nexus** Boosts Magic → `+2x`

Assemble: `3x + 2 + x + 2x`
Collect: `(3 + 1 + 2)x + 2 = 6x + 2`
Roll = 5 → `6 × 5 + 2 = 32`
**Damage: 32** (row `6x + 2`, x=5)

### B. Weaken — same Sorcerer, in Mistfen (still usable)

- Base: pet magic attack `3x + 2`
- Sorcerer High Magic → `+x`
- **Mistfen** Weakens Magic → `−2x`

Assemble: `3x + 2 + x − 2x`
Collect: `(3 + 1 − 2)x + 2 = 2x + 2`
Roll = 5 → `2 × 5 + 2 = 12`
**Damage: 12** (row `2x + 2`, x=5). A non-caster (Low Magic, `−x`) here would land
`3x + 2 − x − 2x = 2` — the `+x` buys the Sorcerer a net `−x` edge.

### C. Cancel — forced switch, in Null Field

- Null Field **Cancels Magic** — no magic block this match.
- The pet's **strength** attack is `2x`; character is **Average Strength** → `0`.

Assemble: `2x + 0`
Collect: `2x`
Roll = 5 → `2 × 5 = 10`
**Damage: 10** (row `2x`, x=5). Worse than a boosted `6x + 2`, but a real turn.

### D. Everything cancels out (`n = 0`)

- Base: pet strength attack `x + 1`
- Character **Low Strength** → `−x`
- Environment does not affect strength → `0`

Assemble: `x + 1 − x`
Collect: `(1 − 1)x + 1 = 0x + 1 = 1`
Every roll → `1`
**Damage: 1** (constant — `n = 0`, not in the table; damage is `c = 1`, floored at the base-attack minimum).
