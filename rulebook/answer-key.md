# Algebra Monster Battle — Fast-Marking Answer Key

A lookup sheet for marking battle worksheets. Once a student has collected like
terms to a single `nx + c`, you do not need to re-derive anything: find the row,
read the value under their die roll, and that is the damage — already floored at
0.

This sheet prints best in **landscape** (the lookup table is wide).

## 1. How to use

For each attack row on a student's worksheet:

1. Check the **expression assembled** — base attack plus each `±x` term that
   applies:
   - character modifier (Magic on magic attacks, Agility on agility attacks),
   - environment **Boosts** / **Hinders** term (magic/agility attacks only),
   - enemy **Strength** modifier,
   - environment **Tests Strength** term, if the card has one (based on the
     *defender's* Strength; this one also applies to **strike** attacks).

   Strike attacks take no character modifier and no Boosts/Hinders term, but
   they do take the enemy Strength modifier and any Tests Strength term.
2. Check the **like terms collected** — the student should land on a single
   `nx + c`, normally with `1 ≤ n ≤ 6` and `−3 ≤ c ≤ 3`.
3. Take that `nx + c`, find its row in the table below, and read the value in the
   column for the student's die roll (`x = 1..6`).
4. That value **is the final damage**. Every cell is already floored at 0 — if
   `n·x + c` would be negative, the cell shows `0`. There is nothing further to
   subtract or clamp.

**If `n = 0`** (all the `x` terms cancelled — e.g. a High-Strength defender in
Frozen Wastes), the expression is just the constant `c`: the damage is `c` on
every roll (floored at 0). This is not in the table.

If the simplified form is otherwise outside the table (coefficient above 6, or a
constant outside `−3..3`), the v1 starter deck cannot produce it — re-check the
like-terms step. (The two-environments-per-match extension in core-rules §11 can
reach `7x`; add that row by hand if you run it.)

## 3. Sample-scenario answers

Worked examples A–D (from `core-rules.md` §5.5) and F, G, H (from
`environments.md` §6), as reproduced in teacher guide §7, resolved in full.

### A. Sorcerer + Sprite, magic attack, in Arcane Nexus, vs a Barbarian (Avg Strength)

- Base: Sprite "Fairy Lights" magic `3x + 1`
- Sorcerer High Magic → `+x`
- Arcane Nexus `Boosts: Magic` → `+x`
- Enemy Avg Strength → `0`

Assemble: `3x + 1 + x + x`
Collect like terms: `(3 + 1 + 1)x + 1 = 5x + 1`
Roll = 4 → `5 × 4 + 1 = 21`
**Damage: 21** (table row `5x + 1`, column x=4 → 21)

### B. Same attack, but the defender is a Paladin (High Strength)

- As A, plus enemy High Strength → `−x`

Assemble: `3x + 1 + x + x − x`
Collect like terms: `(3 + 1 + 1 − 1)x + 1 = 4x + 1`
Roll = 4 → `4 × 4 + 1 = 17`
**Damage: 17** (table row `4x + 1`, column x=4 → 17)

### C. Physical attack ignores terrain

- Base: Ogre "Strike" `2x + 2`
- Trainer is a Ranger → no strike buff
- Arcane Nexus → no effect on strike (Boosts/Hinders only)
- Enemy Avg Strength → `0`

Assemble: `2x + 2` (unchanged — strike takes no character or Boosts/Hinders modifier)
Collect like terms: already simplified, `2x + 2`
Roll = 3 → `2 × 3 + 2 = 8`
**Damage: 8** (table row `2x + 2`, column x=3 → 8)

Against a High-Strength defender (enemy Strength → `−x`):
Assemble: `2x + 2 − x`
Collect like terms: `(2 − 1)x + 2 = x + 2`
Roll = 3 → `3 + 2 = 5`
**Damage: 5** (table row `1x + 2`, column x=3 → 5)

### D. Hitting zero on a low roll

- Base: pet agility attack `2x − 2`
- Blinding Light `Hinders: Agility` → `−x` (flat, any attacker)

Assemble: `2x − 2 − x`
Collect like terms: `(2 − 1)x − 2 = x − 2`
Roll = 2 → `2 − 2 = 0`
**Damage: 0** (table row `1x − 2`, column x=2 → 0; value is exactly 0, and the
floor confirms it never goes negative)
Roll = 5 → `5 − 2 = 3`
**Damage: 3** (table row `1x − 2`, column x=5 → 3)

### F. Hinder cancels a caster's edge

- Base: pet magic attack `3x + 1`
- Illusionist High Magic → `+x`
- Null Field `Hinders: Magic` → `−x`
- Enemy Avg Strength → `0`

Assemble: `3x + 1 + x − x`
Collect like terms: `(3 + 1 − 1)x + 1 = 3x + 1`
Roll = 4 → `3 × 4 + 1 = 13`
**Damage: 13** (table row `3x + 1`, column x=4 → 13)

### G. Tests: Strength reaches a strike attack — fragile defender

- Base: Barbarian pet strike `2x + 2`
- Strike → no character or Boosts/Hinders term
- Enemy Strength: defender is an Illusionist (Low) → `+x`
- Frozen Wastes `Tests: Strength`: defender Low → `+x`

Assemble: `2x + 2 + x + x`
Collect like terms: `(2 + 1 + 1)x + 2 = 4x + 2`
Roll = 3 → `4 × 3 + 2 = 14`
**Damage: 14** (table row `4x + 2`, column x=3 → 14)

### H. Tests: Strength — the "fortress" defender

- Base: Barbarian pet strike `2x + 2`
- Enemy Strength: defender is a Paladin (High) → `−x`
- Frozen Wastes `Tests: Strength`: defender High → `−x`

Assemble: `2x + 2 − x − x`
Collect like terms: `(2 − 1 − 1)x + 2 = 0x + 2 = 2`
Every roll → `2`
**Damage: 2** (constant — `n = 0`, so not in the table; the damage is `c = 2`)
